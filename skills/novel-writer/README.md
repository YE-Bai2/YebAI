# 中文小说创作 Skill

这是一个面向中文长篇小说、网络小说、短篇小说和系列故事的写作技能包，覆盖多题材创作、项目规划、正文写作、编辑与连续性管理。

## 快速开始

- **想在 ChatGPT 里创建专属 GPT：**先看 [GPT_SETUP.md](./GPT_SETUP.md)，里面有可直接复制到 GPT Builder 的名称、描述、完整 Instructions、对话开场白和推荐配置。
- **想了解核心创作规则：**阅读 [SKILL.md](./SKILL.md)。
- **想建立一部长期连载小说：**复制 [PROJECT_BIBLE.md](./templates/PROJECT_BIBLE.md)。
- **想规划单章：**复制 [CHAPTER_CARD.md](./templates/CHAPTER_CARD.md)。
- **想看提示语示例：**查看 [USAGE_EXAMPLES.md](./USAGE_EXAMPLES.md)。

## 在 ChatGPT 内使用

**注意：GitHub 仓库中的文件不会因为上传到 GitHub 就自动变成 ChatGPT 插件，也不会自动创建 GPT。** 当前可行的手动流程是：

1. 打开 [ChatGPT GPTs 页面](https://chatgpt.com/gpts)，选择创建 GPT（按钮名称和可用权限可能因账号/界面版本不同而变化）。
2. 按 [GPT_SETUP.md](./GPT_SETUP.md) 填写名称、描述、Instructions 和对话开场白。
3. 在 Knowledge（知识文件）中上传 `SKILL.md`、`templates/PROJECT_BIBLE.md`、`templates/CHAPTER_CARD.md`。可选上传 `USAGE_EXAMPLES.md`。
4. 在预览区测试构思、续写、润色和连续性审查。
5. 保存为仅自己可用；确认效果后再决定是否分享。

## 建议的长篇写作方法

1. 先建立项目圣经，区分已确认设定、暂定假设和待作者决定。
2. 确认主线因果与人物动机，再按章节卡逐章写作。
3. 每写完 3–5 章，更新连续性日志、人物状态和伏笔表。
4. 将项目档案与已写正文摘要保存到自己的项目文件中。
5. 开新对话时提供最新档案；不要假设 GPT 会自动记住其他对话的完整内容。

## 文件结构

- `SKILL.md`：核心创作技能与工作流程。
- `GPT_SETUP.md`：自定义 GPT 配置指南及完整可复制指令。
- `templates/PROJECT_BIBLE.md`：小说项目圣经模板。
- `templates/CHAPTER_CARD.md`：章节规划卡模板。
- `USAGE_EXAMPLES.md`：多题材使用示例。
