# 中文小说创作 Skill

这是一个面向中文长篇小说、网络小说、短篇小说和系列故事的写作技能包，包含创作流程、章节写作规范、连续性管理与编辑检查规则。

## 在 ChatGPT 内使用

**注意：GitHub 仓库中的 SKILL.md 不会因为上传到 GitHub 就自动变成 ChatGPT 插件。** 如果你希望直接在 ChatGPT 中使用，最简单的方式是创建一个自定义 GPT，并把技能指令放进它的 Instructions。

1. 打开 ChatGPT 的 GPTs 页面，选择创建 GPT（界面名称可能因版本和账号权限不同而变化）。
2. 名称可用：**小说工坊｜长篇小说创作助手**。
3. 描述可用：**从灵感、世界观和人物设定，到大纲、章节正文、润色与连续性检查，陪你持续完成一部小说。**
4. 将 SKILL.md 的内容复制到 GPT 的 Instructions。若输入框长度有限，可复制“角色与目标”“工作模式”“核心创作流程”“长篇连续性与项目记忆”“创作原则”等核心章节。
5. 添加对话开场白，例如：
   - 帮我从零构思一部有差异化卖点的小说。
   - 根据这个创意，设计世界观、主角和主线大纲。
   - 按照我确认的大纲，开始写第一章，约 3000 字。
   - 检查这几章的人物动机、时间线和设定是否矛盾。
   - 把当前进度整理成可保存的小说项目档案。
6. 保存后，在 ChatGPT 的 GPTs 页面打开该 GPT，即可开始写作。

官方入口：https://chatgpt.com/gpts

## 如果你说的“Skill”是可复用技能文件

保留 SKILL.md 即可。它是面向技能式工作流的 Markdown 指令文件；可作为项目资产、上传给支持读取文件的 GPT，或按你使用的平台要求转换格式。不同 ChatGPT 功能对技能文件的原生支持可能不同，不能保证直接上传 GitHub 就会自动安装。

## 建议的长篇写作方法

1. 先建立“小说项目档案”，不要一上来就让模型一次写完整本书。
2. 确认总纲和人物动机后，按章节卡逐章写作。
3. 每写完 3–5 章，更新连续性日志和人物状态。
4. 定期把确认设定、已写正文摘要和待解决问题保存到本地或项目文件。
5. 开新对话时，粘贴最新项目档案，减少跨对话遗忘和设定漂移。
